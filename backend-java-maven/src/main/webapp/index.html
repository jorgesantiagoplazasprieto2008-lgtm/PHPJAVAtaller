Reglas Críticas de Integridad

  • 1. Unicidad en BD: Restricción UNIQUE(encuesta_id, usuario_id) en tokens_otp.
  • 2. Quema Atómica: Transacción JDBC con setAutoCommit(false) en quema de token + voto.
  • 3. Control de Concurrencia: Bloqueo pesimista SELECT ... FOR UPDATE. Respuesta HTTP 409 Conflict ante colisión.
  • 4. Secreto del Voto: Cero trazabilidad hacia el aprendiz. Se genera hash anónimo SHA-256 de recibo.
